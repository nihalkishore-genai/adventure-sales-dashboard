# AdventureWorks Sales Data Analysis Dashboard

## Project Overview

This project is an end-to-end sales data analytics solution built using Excel, MySQL, Power BI, and Tableau. The goal of the project was to transform raw sales data into meaningful business insights through data cleaning, transformation, analysis, and interactive dashboard development.

The project demonstrates practical skills in data analytics, business intelligence, and data visualization by solving real-world business problems using multiple analytics tools.

---

# Tools & Technologies Used

* **Microsoft Excel** – Data cleaning, transformation, Pivot Tables, KPI calculations, and dashboard creation
* **MySQL** – Database creation, data loading, SQL querying, and analysis
* **Power BI Desktop** – Interactive dashboards and business intelligence reporting
* **Tableau Public** – Advanced data visualization and storytelling
* **PowerPoint** – Business insights presentation and recommendations

# Business Insights

* Sales experienced strong growth until 2013, reaching approximately **16.35M**
* Profit margins remained consistently healthy at around **41%+**
* North America generated the highest sales and profit
* Bikes emerged as the top-performing product category
* USA and Australia contributed nearly equal sales revenue
* Top customers showed strong loyalty, indicating high retention potential

# Challenges Faced

### Data Preparation Challenges

* Data was distributed across multiple Excel files
* Presence of duplicates, missing values, and inconsistent formatting
* Maintaining relationships while merging datasets

### Technical Challenges

* CSV import issues during SQL loading
* Database connectivity issues between MySQL and Power BI
* Managing large datasets with approximately 60,000+ rows

---

# Solutions Implemented

* Cleaned and transformed data using Power Query Editor
* Used structured merge operations to preserve data accuracy
* Fixed CSV formatting, encoding, and delimiter issues
* Created dedicated databases for Power BI integration
* Resolved SQL connector and authentication problems
